# Публикация утверждённого дизайна CRMZona

15 октября 2026 пользователь утвердил перенос нового дизайна на основной сайт после резервного копирования. Источник интерфейса — `design/responsive-preview`, коммит `9db76bb`.

В `main` перенесены только `public/` и генерируемые метаданные доставки клиента (`lib/client-csp.json`, `lib/client-delivery.json`, `lib/client-entry.json`). Dockerfile, сервер, схема базы, переменные окружения и производственные команды запуска сохранены. Демо-сервер и тестовые данные в релиз не входят.

Макет: https://www.figma.com/design/otSSCHDYtOz8psV1RYnm7x

Тестовый стенд: https://97c92cc6nk-maker-crmzona-stand-0560.twc1.net/

Основной сайт: https://crmzona.net/ — Timeweb App Platform, приложение 260923, ветка `main`.

## Резервная точка

Предыдущая рабочая версия: `e67bf8b86be7f6c3c8049ed9babc05e51ebeeb5e`. Тег `backup/production-2026-10-15` опубликован в origin. Локально в игнорируемой папке `work/backups/2026-10-15-pre-redesign/` сохранены Git bundle с полной историей, ZIP исходников, зашифрованный экспорт окружения Timeweb и все 174 записи Supabase `app_kv` на 07:36:41 UTC. Проверены полнота экспорта, контрольные суммы и расшифровка.

Чувствительные файлы зашифрованы Windows DPAPI CurrentUser. Инструкция и скрипт расшифровки находятся рядом с архивом. Бинарные вложения Google Drive не дублировались и остаются в прежнем хранилище.

## Проверки и откат

Перед публикацией: проверка клиентской сборки, 114 автоматических тестов и smoke-сценарий. На тестовом стенде ранее проверены все 16 разделов на ширинах 1440, 768, 390 и 320 px.

Для отката интерфейса выбрать в Timeweb предыдущий успешный коммит `e67bf8b` и выполнить деплой. Не менять переменные, домены и данные. Проверить `/health/live`, `/health/ready` и страницу входа. Восстановление базы для отката дизайна не требуется и может перезаписать новые рабочие данные.
