# CRMZona: проверка нового веб-дизайна

Работа изолирована в ветке `design/responsive-preview`, исходная версия — `e67bf8b`.
В `main` изменения не внесены. Не сливать и не переключать основной деплой до утверждения дизайна владельцем.

## Макеты

[Редактируемый файл Figma](https://www.figma.com/design/otSSCHDYtOz8psV1RYnm7x?node-id=3-2).
Пять экранов: обзор desktop/mobile, сотрудники mobile, графики desktop, вход desktop.
В файле есть компоненты, семантические цвета, типографика Manrope и auto layout.

В приложении обновлены все 16 разделов: сгруппированная боковая навигация с поиском,
мобильное меню, обзор с переходами, сворачиваемые формы создания и карточки списков на телефонах.
Графики и финансовые таблицы сохраняют горизонтальную прокрутку внутри своей области.
Шрифт хранится локально; лицензия OFL находится рядом с ним в `public/assets/fonts/`.

## Тестовые данные и запуск

```sh
npm ci
npm run build:client
npm run preview:design
```

Локальный адрес: http://127.0.0.1:8361/.
Демонстрационный вход: `demo@example.com` / `DesignPreview2026!`.
Это общедоступная демонстрационная учётная запись. Не вводить рабочие или персональные данные.

Сервер использует отдельное файловое хранилище во временной директории, создаёт только
вымышленные точки, сотрудников, задачи и график. Производственные seed-данные отключены.
Переменные Supabase, SMTP, Google и внешних AI-интеграций удаляются перед загрузкой сервера.
Внешние камеры и AI-запросы заблокированы. Данные стенда могут сброситься при пересборке.

## Публикация

Для встроенного стенда Timeweb выбрать ветку `design/responsive-preview`, её последний коммит
и отдельные переменные `CRMZONA_DESIGN_PREVIEW=true`, `PREVIEW_HOST=0.0.0.0`.
Не копировать переменные и секреты основного приложения. Порт образа — 8080;
проверка состояния — `/health/live`. `scripts/start-container.js` выбирает тестовый сервер
только при явном флаге, иначе запускает стандартный сервер.

Стенд получает отдельный технический поддомен; основной домен и основной деплой не меняются.
Встроенные стенды делят вычислительные ресурсы с основным приложением.
Альтернативный отдельный контейнер собирается через `docker build -f Dockerfile.preview .`.
Автоматический Vercel-деплой этой ветки отключён в `vercel.json`.
